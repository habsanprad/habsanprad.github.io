# passler.me

GitHub Pages site for <https://passler.me>.

`index.html` is the DP-900 learning deck: one self-contained file with no
network dependencies, built from the source repository `DP900` by
`node scripts/build.js`. To publish a new version, copy the rebuilt
`DP900_deck.html` over `index.html` and push.

`CNAME` binds the custom domain. Do not delete it.
